# EduAI Audit: запуск и работа

Приложение проверяет готовые вероятности по уже известным исходам. Оно показывает,
кого выбрали для проверки, сколько положительных случаев нашли или пропустили,
сколько возникло ложных тревог и как результаты различаются между группами.

## Запуск на Windows

Нужен Python 3.11 или новее. В терминале PyCharm из корня репозитория выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

После первой установки можно запускать `start_app.bat` двойным щелчком. Пока
пользуетесь приложением, держите его окно открытым. Адрес
[127.0.0.1:8501](http://127.0.0.1:8501) работает, только когда локальный сервер включён.
Сервер доступен только на этом компьютере; телеметрия Streamlit отключена.

## Первый аудит

1. Откройте приложение и выберите **Русский** в поле **Language / Язык**.
2. Скачайте пример CSV на стартовом экране и загрузите его обратно. Это вымышленные
   данные для знакомства с интерфейсом.
3. Выберите пресет **Синтетический пример**. Проверьте заполненные поля.
4. Оставьте доли `15, 20, 30` и долю подробного отчёта `20%`.
5. Нажмите **Запустить аудит**. Просмотрите результаты, графики и таблицы.
6. Скачайте HTML-отчёт: он открывается без интернета и включает таблицы и графики.

Переключать язык можно до или после расчёта: настройки и результаты сохраняются.
Имена столбцов, коды групп и ваши текстовые пояснения остаются как в источнике.

## Какие данные нужны

Одна строка CSV должна описывать одну единицу аудита. Нужны известный исход,
готовая вероятность положительного исхода от 0 до 1 и уникальный ключ решения.
Обучение модели и подготовка прогнозов выполняются отдельно. Инструкции по
выгрузке из тетрадки — в [EXPORT_PREDICTIONS.md](EXPORT_PREDICTIONS.md).

| Пресет | Единица аудита | Исходы | Ключ решения |
| --- | --- | --- | --- |
| UPV 2022 | Студент после подготовки исходных строк по курсам | `A` — положительный, `B` — отрицательный | `dni_hash` |
| OULAD | Запись студента на курс за учебный период | `Withdrawn` — положительный; `Pass`, `Fail`, `Distinction` — отрицательные | `id_student`, `code_module`, `code_presentation` |
| UCI | Студент при предположении «одна строка — один студент» | `Dropout` — положительный; `Graduate` — отрицательный; `Enrolled` исключается | `Source Row ID` — технический ключ |

**Ключ решения** отличает одну проверяемую запись от другой. Для UPV достаточно
ID студента; в OULAD нужны студент, курс и учебный период. Приложение отклоняет
повторы ключей и не объединяет строки автоматически.

**ID студента** связывает несколько записей одного человека для расчёта
неопределённости. В UCI реального ID нет: технический номер строки не доказывает
отсутствие повторяющихся студентов. Если ID решения вообще отсутствует, номер
строки можно включить явно; отчёт укажет это ограничение.

**Базовая группа** задаёт точку отсчёта: другая группа минус базовая. Например,
полнота TP 40% минус полнота TC 50% даёт −10 процентных пунктов. В пресете UPV
базой для `dedicacion` является TC, как в PROTOTYPE. Для остальных столбцов база
не выбрана. Изменение базы не меняет отбор и показатели самих групп.

## Как читать результаты

- Полнота — найденные положительные случаи / все положительные случаи.
- Точность отбора — найденные положительные случаи / выбранные строки.
- Доля ложных тревог — ложные тревоги / все отрицательные случаи.
- Доли отбора применяются после исключения исходов; число выбранных строк
  округляется вверх. При равных вероятностях используется исходный порядок строк.
- Подробные результаты по группам относятся к выбранной доле отчёта. На графиках
  представлены все рассчитанные доли.

Интервалы относятся к фиксированным прогнозам и отбору. Они не учитывают новое
обучение модели и изменения будущих наборов студентов. Для малых или разреженных
групп показаны замечания; некоторые интервалы недоступны. Разница между группами
не является автоматическим выводом о дискриминации или причинности. Приложение
не выбирает оптимальную долю отбора.

Режим без известных исходов и AI-объяснения запланированы отдельно.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -v
```

Проверки охватывают входные данные, расчёты и интервалы, соответствие отчёта
расчётам, пресеты, перевод, графики и переключение языка без повторного аудита.
